# Тайный Санта бот (aiogram)

Телеграм-бот для проведения игры «Тайный Санта». Участники регистрируются, оставляют пожелания, организатор скрытой командой `/shuffle` распределяет пары так, чтобы каждый дарил подарок одному человеку и никто не дарил себе.

## Возможности
- Кнопки: «Участвовать» → регистрация с именем, «Мои пожелания» → ввод/обновление списка подарков, «Правила».
- Скрытая команда `/shuffle` только для администратора (`ADMIN_TG_ID` в `.env`). После жеребьёвки кнопка «Участвовать» заменяется на «Кто мне выпал».
- Просмотр получателя: имя, кликабельный контакт, пожелания.
- Уведомление «Санты» при обновлении пожеланий его получателем.

## Локальный запуск через Docker Compose
1. Создай `.env` на основе `.env.example` (вставь токен и Telegram ID администратора).
2. Запусти: `docker compose up --build`.
3. Остановить: `docker compose down` (добавь `-v`, чтобы очистить данные БД).

## Запуск без Docker
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # отредактируй под себя
python -m app.main
```

## Структура
- `app/main.py` — точка входа, инициализация настроек, БД и бота.
- `app/bot/*` — хендлеры, клавиатуры, сообщения, middleware для сессии и настроек.
- `app/services/participants.py` — бизнес-логика регистрации, пожеланий, жеребьёвки.
- `app/models.py` — SQLAlchemy-модели.
- `docker-compose.yml`, `Dockerfile` — деплой через Docker.
